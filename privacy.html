Privacy policy

Running Dashboard is a personal application maintained by Sezdev. The working dashboard runs locally on its owner's Windows computer. This website contains public app information only.

Effective date: 31 October 2026

1. Data the application accesses

The application accesses only accounts connected by its owner. Its Google Health integration uses:

  • Activity and fitness read access: daily step counts and daily total movement distance, including available historical records.
  • Google Health account identity: the account's Health user identifier, to ensure that a connection or export belongs to the intended account.
  • Optional measurement write access: permission to add weight measurements to Google Health and manage measurements added by the app. The implemented export uploads selected Xiaomi weight readings only when the owner enables that destination.
  • Authorization tokens: access and refresh tokens used to communicate with Google without asking the owner to sign in for each request.

Other connected providers may supply running recordings, fitness metrics, planned workouts and body measurements for the local dashboard. Their connections and export settings are controlled separately.

2. How data is used

Google Health data is used to show the owner's daily movement history and trends. Account identifiers help prevent connecting or uploading to the wrong account. Authorization tokens enable the chosen sync operations. Xiaomi weight measurements are sent to Google Health only through the optional weight-export feature.

Google user data is not sold, used for advertising, used to build advertising profiles, or used to develop, improve or train generalized AI or machine-learning models.

3. Where data is stored and sent

Account tokens, account configuration and provider caches are stored on the owner's computer, encrypted using Windows account protection. The dashboard is served on the local loopback address. It does not use this public website as a health-data backend.

Authorized synchronization sends requests directly to the relevant provider. An enabled Google Health weight export sends the selected measurement and its timestamp to Google. Separate optional weight-export settings may also send Xiaomi readings to Garmin or Strava. Google Health readings are not exported to those providers.

There is no developer-operated remote health database for this personal installation. Anyone with access to the owner's Windows account or a separately created backup may be able to access local application data.

4. Retention and deletion

Cached history is retained locally so the owner can review it without repeated provider downloads. Removing the Google Health connection through Data sources deletes its locally stored session tokens and cached Google Health measurements. App configuration and separate sync/export checkpoints may remain locally until their corresponding application files are removed.

Removing a local connection does not revoke access at Google or delete previously uploaded Google Health measurements. The owner can revoke Running Dashboard's access through Google Account connections, and manage uploaded measurements through Google's available controls. The owner is responsible for deleting any separately created backups.

5. Permission controls

The owner can choose whether to connect Google Health, enable or disable weight export, run a sync, or disconnect locally. Disabling weight export stops future uploads through that setting; it does not delete readings already sent. The owner can separately revoke the app's permissions at Google at any time.

6. This public website

This site contains no account sign-in form, health-data upload, analytics scripts, advertising or application tracking cookies. It does not receive the dashboard's authorization tokens or cached measurements. The hosting provider, GitHub Pages, may process technical request information such as IP addresses and server logs under GitHub's privacy statement.

7. Google API data commitments

Running Dashboard's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements. Google data is used only for the personal dashboard and the explicitly enabled features described here.

8. Questions and changes

Contact the maintainer through the Sezdev GitHub profile. Do not include health measurements, authorization tokens or account secrets in public messages. This policy will be updated when the application's data practices change; the effective date identifies the current version.
